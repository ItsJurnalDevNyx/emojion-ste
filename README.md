# Emojion STE - Send The Song

Projekan web berbasis inspirasi "Send The Song" yang memungkinkan pengguna mengirimkan pesan rahasia beserta lagu pilihan secara anonim kepada seseorang. Menggunakan integrasi **Apple iTunes API** untuk pencarian katalog lagu secara cepat dan presisi.

**Demo Aplikasi:** [emojion-ste.netlify.app](https://emojion-ste.netlify.app/)  

---

## Fitur Utama

* **Pencarian Lagu Integrasi iTunes:** Cari dan pilih ribuan lagu favorit langsung melalui Apple iTunes API.
* **Pesan Anonim:** Kirimkan ungkapan perasaan atau pesan khusus tanpa harus menunjukkan identitas pengirim.
* **Audio Preview:** Dengarkan cuplikan lagu yang dipilih sebelum atau sesudah pesan terkirim.
* **Desain Responsif:** Tampilan yang nyaman dan ciamik diakses baik lewat *smartphone* maupun desktop.
